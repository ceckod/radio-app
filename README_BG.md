# Радио – Андроид приложение + Android Auto

Твоят сайт (визия, скрийнсейвър, часовник, любими) работи на цял екран в приложението.
Звукът го пуска плейърът на телефона, затова работят **Android Auto**, бутоните на волана и свиренето при изгасен екран.

## Как да получиш APK
1. Качи `radio-android.zip` в хранилището в GitHub (Add file -> Upload files).
2. Автоматично тръгва **Unzip radio-android.zip** и разархивира файловете.
3. След него тръгва **Build APK**. Ако не тръгне: Actions -> Build APK -> Run workflow.
4. След ~5-10 минути свали резултата **radio-apk**, разархивирай го и инсталирай `.apk`.

## Android Auto
Настройки на Android Auto -> натисни многократно "Version" -> меню горе вдясно ->
Developer settings -> включи **Unknown sources**.
В колата има папки: Любими, Последни и категориите от сайта (Популярни, Рок и т.н.).
Радиата в колата са същите като в сайта и се обновяват от него.

## Как се променя сайтът
Файлът на сайта е `radioapp/src/main/assets/index.html`. Промени в него влизат в приложението при следващо изграждане.

## Бележки
- "Коя е песента?" показва името само ако радиото го изпраща в стрийма.
- Старите папки `openopenradiomobile` и `openopenradioservice` в хранилището вече не се ползват и могат да се изтрият.
