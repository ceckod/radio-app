# Радио – Андроид приложение + Android Auto

Базирано на Open Open Radio (MIT лиценз, github.com/cghislai/openopenradio),
с визията и функциите на твоя сайт: тъмна тема, филтър по стил, България/Светът,
любими, търсене и бутон „Коя е песента?“ (името идва от стрийма, без прокси).

## Как да получиш APK (без да инсталираш нищо)
1. Направи безплатен акаунт в github.com и ново хранилище (repository).
2. Качи съдържанието на тази папка в него (Add file → Upload files).
3. Отвори раздел **Actions** → **Build APK** → **Run workflow**.
4. След ~5–10 мин свали от резултата файла **radio-apk** → разархивирай → инсталирай .apk на телефона.

## Android Auto
Настройки на Android Auto → натисни многократно „Version“ → меню горе вдясно →
Developer settings → включи **Unknown sources**. След това приложението се появява в колата.
В колата има папки: Любими, България, Жанрове, Държави, Езици, Всички радиа.
